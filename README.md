# Les mesures de l'informatique en 3D

4 scènes 3D : stockage (bit à pétaoctet), débit, fréquence, pixels, avec éléments numérotés, définitions et petits calculateurs.

## Utiliser sans Internet
1. Ouvre le site une première fois avec Internet.
2. Attends que l'étiquette en haut à droite affiche **« ✓ Prêt hors ligne »**.
3. Ensuite, le site fonctionne sans connexion, même après avoir fermé le navigateur. Sur téléphone ou ordinateur, tu peux aussi l'installer (bouton **Installer** ou menu du navigateur : « Ajouter à l'écran d'accueil »).

Autre possibilité : décompresse le dossier et ouvre simplement `index.html` : tout est inclus, Internet n'est pas nécessaire.

## Mettre en ligne sur GitHub Pages
1. Crée un dépôt public nommé `mesures-informatique-3d`.
2. Envoie **tous** les fichiers du dossier à la racine du dépôt (`index.html`, `three.min.js`, `sw.js`, `manifest.webmanifest`, les 2 icônes).
3. Settings, Pages, Branch `main` et `/ (root)`, Save.
4. Lien : `https://zacksslecapitaine1-pixel.github.io/mesures-informatique-3d/`

Si tu modifies le site plus tard, change `VERSION` dans `sw.js` (par exemple `v2`) pour que les appareils reçoivent la mise à jour.
